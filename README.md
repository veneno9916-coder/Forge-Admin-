# ⚡ FORGE ADMIN


## 📌 Overview

**FORGE ADMIN** is a universal, high-performance Roblox administration suite built on a completely overhauled. Designed from the ground up for modern Roblox executors across both **Android Mobile** and **PC Desktop** platforms, FORGE ADMIN bridges the gap between raw command-line power and an intuitive, visual user interface.

Unlike standard admin scripts that require typing out commands manually in a small text bar, FORGE ADMIN introduces a category-driven layout, live server inspection systems, interactive physics sliders, custom execution notifications, and a 10-second cinematic boot sequence—all while maintaining **100% full compatibility**.

🔥 Key Features & Highlights
🎬 10-Second Cinematic Boot Sequence
Monochrome Glassmorphic Splash Screen: A high-contrast black-and-white startup interface featuring your custom centered logo.
Dynamic Terminal Status Logs: Features real-time animated loading updates cycling through system checks
Smooth Tween Transitions: Uses Roblox TweenService for fluid element scaling and a high-speed blur/fade-out transition.

🎨 High-Contrast Monochrome UI & Custom Branding
Pure White & Charcoal Palette: Sleek white panels with crisp black text, sharp outline borders, and dark rectangular command tiles for maximum readability.
Categorized Tab Navigation: Commands are neatly organized into dedicated tabs (MOVE, TP, VISUAL, UTILITY, FUN, PRESETS), eliminating the clutter of traditional scrolling lists.
Header Controls: Complete with custom branding, Minimize (-), Settings, and Close (X) controls.

🎛️ Interactive Movement & Physics Sliders
No Manual Typing Required: Adjust core movement parameters instantly using smooth UI sliders directly within the MOVE category tab.
Supported Sliders: Real-time adjustments for WalkSpeed (ws), JumpPower (jp), and Fly Speed.

👥 Live Player Inspection & Teleport Suite
Server Leaderboard Extraction: Automatically pulls live player data from the server into an interactive player list inside the TP category.
Instant Action Buttons: Click or tap any player's name to execute immediate actions:
Teleport To: Instantly position your avatar next to the target.
Bring: Pull the target player to your location.
Spectate: Lock your camera onto the target player seamlessly.

🔔 Custom Status & Execution Notifications
Clean Alert Overlays: Replaces old dark notification pop-ups with minimalist status boxes.
Success & Failure Alerts: Displays clear, non-intrusive status badges (COMMAND EXECUTED SUCCESSFULLY with a checkmark icon or FAILED COMMAND with an X icon) directly on the interface.
📱 Touch-Friendly Mobile Optimization
Fluid Dragging: Features touch-compatible dragging powered by UserInputService for smooth repositioning on mobile screens.
Persistent Floating Toggle: Features a draggable, circular logo button in the top corner to quickly show or hide the main panel with a single tap.
